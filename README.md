# SCWU Web MVP

Ryuko or Zoma on Sport Court, in free practice or against the original CPU playing either one, built with TypeScript, Svelte 5, Phaser 3, Vite, and Vitest. Includes free practice, the original CPU opponent recovered from each fighter's CPU table, forward/backward movement, dashes, double jumps, standing/crouching/aerial attacks and guard, three-step standing attack chains, Drill Punch, Hit Up launcher and jump chase, the three-part IORI chain, Axe throw, close-range throws, the Daisetsuzan Oroshi command throw, a power gauge with three stocks, Ryuko's five supers (Getter Beam, Musashi, Getter Change Attack, Black Getter Mega Rush, Mega Getter Beam) and NO SUPER, Ryuko's original motion commands alongside single-key shortcuts, EX mode with its charged EX Fire, Ryuko's recovered voices and sound effects, knockdowns and get-ups, hit/block reactions, KO/victory/draw animations, health, first-to-three Vs. CPU matches of 60-second rounds, pause, reset, and touch controls.

## Run

Use Bun 1.3.9+, Node 24.12+ for the tooling CLIs, and Python 3.10+. Keep the supplied `scwu-web-handoff/` directory beside `package.json`.

```sh
bun install
bun run dev
```

Open the localhost address Vite prints. `predev` converts only the required art with the handoff's standard-library Python decoder. Missing or changed Ryuko source data produces an explicit error. No Python, Windows runtime, original executable, or backend is needed by the browser.

```sh
bun run validate # export assets, formatting, ESLint, types, Vitest
bun run build    # export assets, types, production build
bun run preview  # serve the production build locally
bun run format  # apply Prettier
```

`bun run test` and `bun run check` expect assets to have been exported once (`bun run assets`). Husky's pre-commit hook runs `bun run validate`; `bun install` installs the hook when this directory is a Git checkout. Use `bun install --frozen-lockfile` for reproducible installs from `bun.lock`. Run `bun run test` to use Vitest; `bun test` selects Bun’s built-in test runner. No commit or remote is created automatically.

Below the arena, choose your fighter, Ryuko (the default) or Zoma, and the opponent, Zoma (the default) or Ryuko, in either mode. Free practice has no timer, and there you also choose the partner's behavior: stand still, hold a standing or crouching guard, jump and guard in the air, punch once a second when you are in range, back away and jump in with an air kick, or play the original CPU (the same one as Vs. CPU, without the round timer). Zoma has his normals, movement, Hit Up, Chuck, COUNTER HIT, specials and supers, and takes every one of Ryuko's moves in his own poses. **Max stock** tops each fighter up to three stocks whenever they stand idle, and **Low health** holds Ryuko at 30% health for the desperation moves. These settings apply at once and persist across resets. The partner uses the same rules as the player; apart from the original CPU, its behaviors are authored for testing. Vs. CPU plays the original game's CPU. Every half second or less, it picks a move from its fighter's recovered CPU table by distance, odds and who is airborne: walks, jumps, dashes, punch and kick strings, Hit Up, the specials and the supers (NO SUPER without stock), with Ryuko's own two-strike IORI and Zoma's own dashes. It blocks about half of the hits that reach it while it is free to guard. Each Vs. CPU round opens with the game's logo wiping away over each fighter's recovered intro: Ryuko's walk-in and transformation (1.99 seconds), or Zoma's stance where Ryuko's walk would end (2.00 seconds). At 3.51 seconds "DRESS 1" calls the round, and at 6.31 seconds "SHOW TIME" starts it: input, the CPU, and the round clock start then, and buttons held through the intro must be pressed again. Every round ends with the original KO lettering and voice, a time-out included. A Vs. CPU match goes to the first to win three rounds; a draw or double KO counts for both, so it lasts at most five. After a win the fighters hold their result for 6.51 seconds (6.52 after a perfect, 3.01 after a draw), then the logo wipes back in and the next round opens with its own call ("DRESS 2" and so on). Each new round restores full life and ends EX mode, but both fighters keep their stock and power. The three marks beside each life bar light as that side wins rounds, and the match's result appears below the court where the next round would have begun. Tick **Music** above the arena for Sport Court's track, which the original keeps silent in this matchup. Changing modes or Reset restarts the match. Leaving the window pauses the match and clears held input; resume explicitly. Touch buttons support simultaneous movement and actions. Landscape is recommended on phones.

Hold crouch while attacking or guarding for low poses; attack or guard during a jump for aerial poses. Every attack strikes from its recovered hitbox, and every pose is hit through its own recovered body box. Centre to centre against a standing opponent, the standing punch and kick reach about 260 and 280 arena pixels, the air kick about 150, and Kick 3's beam about 550. Crouching or walking narrows the body, so attacks reach a little less; a backdash cannot be hit once it leaves the ground, and a grab cannot be struck on its grab tick. Life is the source's 510 points. A hit takes the striking box's damage, 20% more against most attacking poses. A guard takes nothing, except 20% chip from IORI, the drills, the axe and most super boxes, and chip can KO. At 30% life (153) or less, every loss shrinks to 60%. When the opponent crosses over, a grounded fighter plays the recovered 100 ms standing or crouching turn before walking or idling again; any other input interrupts it. The crouching kick sweeps: a hit pops the victim into a short knockdown and get-up. Attacks finish before another can start, except through the recovered chains and cancels below. Landing interrupts aerial attacks, and an air hit or air guard ends the moment it lands. Airborne fighters land before their round-result pose. KO plays the recovered lettering sequence for 166 ticks (1.66 seconds); in free practice, one second with the winner visible follows before the result. Rematch controls appear below the court, keeping the ending poses unobscured.

Punch and kick chain only after contact. When punch 1 or kick 1 hits or is blocked, it switches to its hit branch; 180 ms later (the 100 ms contact pause plus the branch's first 80 ms pose) the branch looks back 200 ms (250 ms for the kick) for a fresh punch or kick press made after a moment with no direction held. Punch enters punch 2 and kick enters kick 2, so the chains cross. A whiff has no follow-up. Punch 2 checks the same way after each of its three strikes, and kick 2 once after its strike; a press there cancels at once into punch 3 or kick 3, even on a whiff. Punch 2 and kick 2 open with a lunge of about 117 and 99 arena pixels, which carries them back into range after the victim's slide. The second standing punch and jumping kick each have three strikes; the third standing kick has eight. Each strike has its own active window and hit/block effect, with inactive gaps between strikes. Their total damage stays at 10, 13, and 17 respectively. Holding an attack never repeats it, and a hit on the attacker ends its chain. Jump direction is chosen when jump is pressed: neutral jumps rise about 318 arena pixels, while forward/backward jumps rise about 296 and travel about 348 pixels when unobstructed. Jump travel continues after releasing direction and through aerial attacks or guard. Double jumps pause for 30 ms before launching in the newly selected direction. These velocities and acceleration use recovered actions 4–6 and 10–12, converted from the original fixed-point units to the arena scale. In the air, up, ↗ or ↖ pressed from neutral double jumps. A direction, neutral, then the same direction again within 130 ms dashes that way, on the ground or in the air, on keyboard or touch; Shift dashes forward, or backward while back is held. A jump allows one double jump and one air dash, and a double jump can still air dash; an air dash or a finished aerial attack allows neither until landing, and neither comes out within 50 source pixels of the floor on the way down. Ground dashes launch after 50/100 ms of preparation, hold their airborne pose until landing, and land through Dash F lend (action 15, 80 ms). Actions 13–14 set forward/backward velocities of +900/-500, upward velocities of -500/-900, and gravity 90 in source units. Unobstructed hops cover about 243/247 arena pixels in 180/330 ms, respectively; the backward hop is higher and slower. Air dashes retain the incoming jump or fall motion during their 30 ms preparation; if that fall reaches the floor, they land before launching. At launch they replace it with level motion at about 12 arena pixels per tick: 300 ms of level travel forward (about 360 pixels), or 200 ms backward (about 240 pixels). Their 100 ms recovery restores gravity while keeping horizontal velocity; that drift continues through the fall that follows until landing, and the guard key waits for the landing, since the fall is still the dash's (action 7, entered by its jump). A dash that reaches the floor before that fall ends at once, free. Actions 16–17 supply velocity ±800 and gravity 80; the recovery motion flag `0x02` retains horizontal velocity, as does the following fall action 7. A forward air dash near the neutral-jump apex covers about 720 arena pixels through landing when unobstructed. The 960-pixel viewport scrolls over a 1920-pixel stage, so crossing the old screen edge no longer cuts off the move. Actual stage walls and body collision can shorten travel. Ground Drill Punch lunges from action ticks 11–59 (110–590 ms before contact pauses) at about 13.5 arena pixels per tick, slides at about 1.5 pixels per tick until action tick 69, then stops for its remaining recovery. Contact pauses stop this movement clock as well as the poses. Body collisions and arena walls limit its travel. It advances through six timed strikes for 3 damage each (18 total), with hit reactions and sparks on every contact; the sixth strike launches the victim. Guard blocks all six strikes. The aerial drill holds its 220 ms startup, then dives forward at about 12 arena pixels per tick and downward at about 15; follow-up stages increase the downward speed to about 22.5. It spins until landing. Hit or block advances its contact stages; a missed spin stays armed. Damage drops from 16 to 5, 3, then 1 per subsequent contact, so its hit count depends on contact and airtime; a 1-damage spin that passes without contact returns to 3. A hit slams the victim down into a floor bounce, and an airborne victim is struck again by each stage until it lands. The attacker holds position for eight contact ticks, then moves through the two transition ticks before the next strike. Landing ends the attack and plays its recovery. Its spinning box reaches about 189 arena pixels ahead. Axe throw releases a spinning axe 160 ms in, flying at about 13.5 arena pixels per tick; pressing it again while that axe flies only makes Ryuko stand. The command stays in its 400 ms window, so she keeps standing until the axe's hit stops her, and throws another if the window is still open then. It hits through body boxes like any attack (36 against an attacking pose), so it passes through a fighter mid-throw and under a high enough jump, and it can be blocked. Two opposing axes break each other where they meet, the Mega Getter Beam's beam breaks every opposing axe, and its lunge meeting an axe enters its hit cinematic. A super's freeze holds a flying axe in place without its hitbox, and an axe vanishes 75 pixels past either end of the stage. These two basic specials are meter-free.

Press H or the Hit Up touch button on the ground for an upward kick. It steps forward about 120 arena pixels, strikes after 150 ms of action time, and deals 15 damage. A grounded hit pauses the attacker for 330 ms and the victim for 100 ms; the victim then holds the impact pose for 250 ms before rising about 589 arena pixels and falling into knockdown/get-up. Press or hold Jump in the last 150 ms of the contact pause or the first 50 ms after it to chase them, then use an aerial attack; an earlier press is too early. The chase prepares for 80 ms and preserves its forward momentum in the air. Blocking or missing plays the full recovery without a chase. An airborne victim instead takes a shorter hold and a stronger outward launch. The camera stays locked to the player: launching the opponent does not pan the view, while chasing them follows your own movement. The HUD stays fixed. The H binding, early Jump buffering, and camera following are training choices.

Press F or the IORI touch button on the ground for a three-part advancing attack. Each stage checks for IORI's ↓← and J (F enters them too) three times after its strike: at 290, 490 and 540 ms of its own time for the first, 310, 510 and 560 ms for the second, each looking back 300 ms (200 ms at the last). A match starts the next stage at once. Holding the button performs one stage. You can continue on hit, block, or whiff. After contact, a press early in the hit pause can be too old: the cancel window's command checks clear all but the last 200 ms of input each time they find IORI's command. Damage is 15 + 18 + 20 (53 total); a guard takes 3 + 3 + 4 chip. The first grounded hit pushes away, the second pulls inward, and the finisher launches a grounded victim away or slams an airborne victim into a bounce and knockdown. Without follow-up input, each stage completes its recovery. Once a stage connects, a super cancels it (see below). The F binding is a training choice.

Press G or the Daisetsuzan touch button on the ground for Ryuko's command throw. 40 ms into the move, its grab box reaches an opponent up to about 259 arena pixels away, including one reeling from a hit, but not one blocking or turning. Started farther than Ryuko's near distance (about 165 arena pixels), the command plays DST FAR instead, whose shorter box reaches only 169 but stays open through the whole move: DST FAR never clears it, so it grabs an opponent who steps in during its recovery. A miss plays a 580 ms recovery. On a grab, Ryuko spins the opponent overhead for 1.8 seconds, then hurls them into the sky for 10 damage. As they fall, Ryuko slides back and fires two missiles; the lower one catches them for 22 damage, and the other passes just beneath. The missile hit spins them away into a bounce, knockdown, and get-up. The held opponent cannot be hit. Time running out doesn't stop the spin: the toss still lands. A lethal toss still finishes Ryuko's sequence before the victory pose. At 30% health or less, G performs EVIL DST instead: the same grab and miss recovery with its own poses, then five held strikes (1.65 seconds, 25 power, no damage) before the usual spin, toss and missiles.

Press E or the EX mode touch button on the ground to enter EX mode for 50 power (half a stock), and again to leave it for another 50; with less, Ryuko plays NO SUPER. Ryuko flashes for 200 ms, and her HUD face blinks an EX mark while EX mode lasts. In EX mode, I fires EX Fire instead of the axe. Holding forward charges it, checked every 10–50 ms from 180 ms after the press. Let go before 510 ms for a 30-damage shot, a little slower than the axe, or later for a faster, 40-damage one. Holding through 770 ms fires a large 50-damage shot that launches the opponent, with a bigger recoil. As with the axe, a second press while a shot is out only stands for a tick. Opposing shots and axes break each other. Key 1 on the ground fires EFS instead of Getter Beam: four shots and a launching final one for a stock, or two when it cancels IORI. In Vs. CPU, holding down as the round's intro reaches its last poses starts the round in EX mode.

Hits, blocks, and damage taken fill the power gauge at the bottom of the screen. Each full gauge becomes a stock, up to three; there is no free meter in practice. Keys 1–5 or the gold touch buttons spend stock on the supers. Without enough stock, Ryuko plays NO SUPER for 400 ms and gains 10 power instead. Each super freezes the opponent while Ryuko transforms. Getter Beam fires a screen-long beam that hits 20 times for 100 damage; a guard takes 1 chip from each. Pinned against a wall, the opponent's slides push Ryuko back, and the beam moves with her. At 30% health or less it becomes the stronger desperation beam (120 damage). In the air, Ryuko hovers while firing, then falls. Musashi and the Getter Change Attack are unblockable grabs, though both pass over an opponent still reeling from a guard, and the Change Attack also over one in the air or reeling from a hit: Musashi lifts the opponent overhead and slams them for 120 damage. Cancelled from IORI, Musashi also catches an opponent in the air. The Change Attack repeats the Daisetsuzan spin, tosses the opponent, catches them in the sky, throws them and fires a beam as they fall. Key 4 throws an axe until Ryuko's health falls below 30%, then performs the seven-strike Black Getter Mega Rush for 125 damage. The Mega Getter Beam needs all three stocks: its opening blast shocks the opponent, then a cinematic beam from the sky hits 40 times; 240 damage in all. A hit on Ryuko cancels her super, including a beam already on screen.

Every attack chooses its victim's reaction from the recovered response table: standing, crouching or airborne, each guarded or not. Air punch and air kick are overheads, hitting a crouching guard and pushing a standing guard back. Punch 3 slams any grounded victim into a floor bounce, even through a crouching guard; once the bounce starts, attacks that reach its low body (kicks, crouching attacks, IORI) strike the victim again. An air guard stops only aerial attacks, punch 3, IORI, the drill and the axe; the ground normals and Hit Up hit it. Each grounded reaction then slides as in the source: a light hit about 84 arena pixels, a heavy hit 214, an air attack's hit 71, a light block 96 and a heavy block about 204. A beam hit (kick 3, Getter Beam) pushes the victim back for 25 ticks, then drifts it in again: about 12 pixels between kick 3's strikes and 18 between Getter Beam's. Air hits rise briefly, then fly the victim up and away; an air guard slides back, speeding up, as it falls. An air reaction that lands ends at once, so the fighter can act on the landing tick; one that runs out in the air becomes a normal fall.

Specials and supers cancel an attack once its own strike has hit or been blocked: punch, kick, the crouching attacks, punch 2 and kick 2 accept the drill, IORI, DST, the axe and every super. Punch 1's and kick 1's hit branches accept them at once. The press counts on any tick, including the contact pause; the new move starts when the pause ends. A connected air punch accepts the air kick, Air Drill, the air Getter Beam or a double jump; a connected air kick accepts the same except the air punch. Air attacks after a double jump or during an air dash cannot double-jump cancel; air dashes accept air attacks and the air specials from their fourth tick, and those attacks fall more slowly. A connected IORI stage accepts only keys 1–4: this super cancel plays the SC version, costs two stocks (NO SUPER otherwise) and flashes GENGAI!, and the hidden super's cancel plays NO SUPER at 150 of 510 life or more.

While a standing or crouching guard reaction plays and Ryuko has a stock, press H to COUNTER HIT: she spends the stock, freezes the attacker and swings a wide blow that launches them. The press counts at the guard reaction's recovered checks, including one up to 80 ms before the block. Air guards cannot counter.

Press O to grab an opponent, including one holding guard. The grab checks after 70 ms: its box reaches a standing, crouching or attacking opponent on the ground up to about 167 arena pixels away, but not one airborne, turning, reeling from a hit or blocking. A miss plays a 620 ms recovery. Ryuko cannot be struck on the grab tick, so a punch landing then passes through her, and two simultaneous grabs both miss. A grab holds the opponent in front for 50 ms and spins them through three 200 ms cycles, as the Daisetsuzan's first spins do, then tosses them into the air for 30 damage. Ryuko's recovery lasts 1.4 seconds. The opponent tumbles, bounces into knockdown and gets up before control returns. The held opponent cannot be hit; the tossed one can, until knockdown (its 129–131 body boxes are kind 2). A lying fighter's body sits below the floor and a rising one has none, so neither can be hit or grabbed. Knockdown and get-up keep push boxes, so bodies still push apart. Fighter anchors stay 185 arena pixels from either stage edge so the extended air dash and wide throw/recovery poses remain visible without shifting position when the pose changes. A hit on the thrower before the toss frees the opponent without damage. A lethal toss KOs the victim where it was tossed; reset releases held fighters.

## Evidence and deliberate limits

- **Recovered behavior:** `src/game/standing.ts` ports the verified standing interpreter, including variable/collision-record assignments, branching, unsigned LCG arithmetic, timing accumulator, explicit unsupported-opcode errors, and odd-width facing placement. It executes instructions at fixed 10 ms ticks, independently of Phaser rendering. Idle action-end restarts action 1 with the continuing random seed as a new prototype choice.
- **Acceptance:** Vitest compares every event, branch, instruction, final PC, timer, and seed against 21 independently generated Python traces. The supplied seed-0 handoff timeline is also compared directly: 18 displays, nine images including 295, 223 ticks. These are comparisons against the supplied research; the original Windows game has not been run here.
- **New rules:** `match.ts` defines prototype movement, gravity, body separation, guard, hitstun, and round flow. Non-idle animation clips use deliberately selected display poses and offsets from the containers; they do not claim to execute those actions' original bytecode, physics, collisions, or transitions. CPU uses the same Ryuko art. Camera/crop is a new presentation choice.
- **Animations:** `animations.ts` loops locomotion/crouch, plays finite action and reaction sequences, and holds final airborne/ending poses. Recovered costume changes are preserved. Timing is authored where source commands wait for gameplay. Ryuko's normals (178–194), Hit Up (200–202), dashes (13–17), Jump 2 (10–12), specials and supers (see Supers) play from their own flattened timelines, as Zoma's moves do (see Ryuko's moves): Drill Punch 207 and Air Drill 208–212; the axe throw's “FIRE START” (226), whose object is “Fly Ball” 227 with impact 230; IORI 246–248; DST 214–224 with its missile objects 218; the chuck 196–199; EX Ch 204–205 and CPU IORI 410–411. Aerial drill follows the contact-dependent stages of actions 209–211, each spin's hit and guard handlers entering its next, rather than playing a fixed number of spin cycles; a spin of 211 that passes without contact jumps back to 210 (PC 3060). Jump, dash, and drill movement use recovered opcode-1 velocities at source speed 10, converted to the web art scale. Air-dash entry preserves airborne velocity until the first motion command (PCs 205/223); the original action-change path at `0x410d50` clears motion only on the ground. Opcode `0x1e` controls action cancellation eligibility, not dash acceleration. Per-contact fighter pauses use recovered response timings described below. Neutral, guard, victim and result states keep clips the match drives itself; the normal KO uses the recovered motion described below. Kick 3 now uses the source BEAM hit and no-time-lack guard pose sequences (83–84, 163, 165, 167). Victim reactions follow the recovered responses and motion described below. While its axe (slot 6) lives, flying or breaking, axe throw 226's op `0x04` at PC 3267 jumps to action 225, which shows one display and returns to neutral, so the axe flies on; PC 3279 would likewise jump to punch 178 rather than spawn a second, which can't happen once 226 has started without one. With EX mode's player variable 0 at 10, PC 3266 enters EX Fire (231) instead (see EX mode). Sixteen ticks in, 226 spawns action 227 at (−6, −102) (PC 3279). Action 227 moves at raw 900 (PC 3293) and re-sets box (63, 3, ±39, ±44; kind 6, damage 30) every 3-tick display; handlers 2 and 3 (hit, guard) enter impact 230. Action 227 loops until deleted: `0x4124c9` deletes an object that doesn't follow its parent once it leaves x −50..1330 or y −50..1010 source pixels (the floor is y 920, `0x412247`), the DST missiles too. After each display, 227's op `0x1f` (PCs 3297–3318) checks global 6 (`0x4456bc`, selector `0x86`): while it is above 0, the axe zeroes its motion and box and replays that display. Supers and COUNTER HIT add their freeze to global 6 beside their op `0x1a` stops (Getter Beam 10, then 65 at age 5), and KGT action 58, the stage layout, counts it down every tick except while paused (PCs 366–371), so an axe holds from its next display through the first after the freeze. Each tick the engine sorts objects into 128 priority buckets (`+4`) and runs their scripts bucket by bucket, slot by slot (`0x404d0b–0x404d89`), before the hit test and motion. KGT objects spawn at `0x65` (`0x406890`'s callers), after the fighters (`0x50`) and the axe and missiles (op `0x04` flag 1, one in front of their spawner; 0 behind, 2 from byte 13), so the countdown follows every read. The DST missile (218, PC 3168) holds one display only when global 6 is exactly 1. Shortcut: the port moves each object before its script step, at the velocity its last step set, where the source's motion pass (`0x40f910`) follows the scripts, so a velocity a script changes applies a tick late: the missile moves once more before that hold. ## Recovered contact timing

A strike's active/inactive cycle uses **action ticks**. Successful contact adds **hit-stop**: the fighter's action age, airborne age, position, velocity, and acceleration stop advancing for the specified ticks. This is separate from the victim's subsequent hit/block recovery. One tick is 10 ms in this port. Whiffs add no pause. Effects, the round clock and the input history continue, so chain and cancel presses count during the pause. After a KO or time-out the round phase stays 1 (only a debug key sets 2, `0x406231` and `0x408f38`): moves, objects, commands and the CPU run on, and each fighter takes its result's action once back in neutral (`0x410ff1`); only the timer stops (`0x408e50`).

The original handoff stays unchanged outside `public/`. Vite explicitly denies serving it, including through `/@fs/`. Only selected PNGs enter `public/assets/`; generated assets and fixtures are ignored by Git and regenerated locally. `dist/` contains those selected original assets and is for private development. This MVP does not publish them or establish redistribution rights.

Phaser uses its [scene lifecycle](https://docs.phaser.io/phaser/concepts/scenes); Git hooks follow [Husky's current setup](https://typicode.github.io/husky/get-started.html).
