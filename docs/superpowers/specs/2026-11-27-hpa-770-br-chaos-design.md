### Native waiting slots and bounded recycling

Match already instantiates slots, uses 32-bit physical masks and counts native hostiles (including waiting ones). LONG can have >10 native seats; MAX_FIGHTERS=10 only gates summons. CHAOS alone has four permanent enemy story seats plus 1P and optional ally, at most six natives. Keep lanes keyed by story seat number; resolve compact fighter indices through `seats`/`bySeat` so No partner dropping slot 5 needs no separate mapping. A small mutable cursor per lane consumes the immutable queue; remember which story seat holds the most recently **assigned** entry (initially the second waiting slot). At most one waiting slot per lane; `arrive()` remains the *only* entry gate, using the watched fighter's current HP and scaled `lifeMark`. No latch on temporary low life, separate scheduler or pre-entry cascade.

**Refill rule:** a present, downed lane occupant becomes eligible after **CHAOS_RETIRE_TICKS = 120** complete simulation ticks from first observed downed (1.2 seconds at 10ms/tick), provided its hitStop is zero and its lane has another unseated enemy; otherwise leave it alone. Record first-down tick once per occupant, reset on replacement. Count completed Match steps, not wall time or KO animation age; evaluate only after normal script/contact/KO/result processing at the end of a tick, not mid-hit pass; do not refill during result transition or after player loss. If a KO stop is still active at 120, wait until the first eligible boundary. This authored window exceeds the native 40-tick KO hold and permits a bounded KO presentation without waiting for indefinitely held KO animations. Record it in evidence.md; pin age 119, 120 and extended stop cases.

At most one refill per lane at each boundary, stable lane/seat order. If the lane still has a native waiting successor, do not retire the watched predecessor (or refill that lane) until `arrive()` has run and it has entered. Once both occupants entered, retire an eligible KO, copy the next enemy into that same seat as a normal waiting slot and update the lane's latest-assigned seat. Its watch is:
- If the most recently assigned predecessor is in the other seat, watch that seat with `below = desperationOf(predecessor.who)` and native re-read semantics.
- If the predecessor itself is the retired occupant (newer enemy KO'd before older enemy), its KO already satisfied the gate. Set watch to an explicitly absent story seat (-1) and below to the retired predecessor's positive desperation mark; native `bySeat`/ `arrive` resolves missing life to zero, so it enters on the next native arrival pass. No threshold latch.
- On two KOs together, refill one seat only; let its waiting replacement enter while the other downed predecessor still exists (or via absent-seat watch), then consider the other seat. Never overwrite a slot still being watched. A freshly waiting replacement at full HP cannot trigger another refill. The other lane is independent.

These guards are necessary corrections to the review's proposed unconditional other-seat watch and simultaneous refill: A2 could KO before A1, and replacing a watched A2 with full-life A4 before A3 arrives would block the queue. Test both orders and simultaneous KOs; do not require older enemies to die first. An enemy still alive above its current threshold can delay the next entrant, as in native B.R. Use the existing arrival phase, strict below comparison and scaled mark; 1P ally keeps native waiting behavior.

## 3. Scene: reuse existing loader with a pre-step residency invariant

`whenReady` loads only the initially seated fighters, not the queue. Reuse `loadPlayer`, `residentPack`, `unloadPlayers`, existing loader COMPLETE/error handling and `wanted` match identity. Match exposes only the next unseated Who in each lane as lookahead. Keep set = seated (including waiting/KO'd natives) ∪ current summons ∪ at most one unseated queue head per lane. **Before each actual fixed step** on CHAOS check the full keep set for residency (not just already seated): otherwise a refill during that step could reference missing art before the next gate, during sound/idle/render processing. Request missing heads through existing loadPlayer/loader, adopt completed resident packs into players, skip ticks while loading, no catch-up. Prefetch heads before the first step and after each consumption. No new request subsystem, async input order, token generation, or separate retry UI. If a pack fails or is absent at COMPLETE, use the existing scene error path; check residency even if a summon coalesced the same load. A stale COMPLETE can register actual resident packs but must not install a fighter or clear a newer route's loading flag: existing wanted/match identity guard, and unload extraneous packs on the current match's next safe keep-set sweep. No mutation of Match from a loader callback; only fixed steps consume queues. Preserve stage/music and normal pause/menu/reset/summon behavior; existing failure path, not recoverable auto-retry. Reset the fixed clock on resume as appropriate, no accumulated load-time ticks.

Extract the small scene per-seat installation from spawnSummon (idle VM initialization, idling flag, palette, sprite pool). Detect replacement by `match.fighters[i] !== drawn[i]` (fresh Fighter identity, no generation ID) **after step, before consuming sounds, idle or drawing**; reset retired seat's voice and stale actor-dependent visuals, install the new idle VM and palette. Unload the retired-only pack after its last render/effect refs are detached (existing unloadTextures resets image textures/removes sounds); before requesting the newly exposed lookahead, sweep keep set to release old native pack. If another occupant/summon/head shares its Who, retain pack. Do not restart match via whenReady or restart stage music. Bound ≤6 seated natives + ≤2 unseated heads + actual summons, boot/stage assets separate; verify wanted/resident set with a Phaser-stub test, not devtools memory sampling. One committed refill-with-load E2E confirms actual renderer/load path. No generalized streaming framework.
