### Native waiting slots and bounded recycling

Match already instantiates slots, uses 32-bit physical masks and counts native hostiles (including waiting ones). LONG can have >10 native seats; MAX_FIGHTERS=10 only gates summons. CHAOS alone has four permanent enemy story seats plus 1P and optional ally, at most six natives. Keep lanes keyed by story seat number; resolve compact fighter indices through `seats`/`bySeat` so No partner dropping slot 5 needs no separate mapping. A small mutable cursor per lane consumes the immutable queue; remember which story seat holds the most recently **assigned** entry (initially the second waiting slot). At most one waiting slot per lane; `arrive()` remains the *only* entry gate, using the watched fighter's current HP and scaled `lifeMark`. No latch on temporary low life, separate scheduler or pre-entry cascade.

**Refill rule:** a present, downed lane occupant becomes eligible after **CHAOS_RETIRE_TICKS = 120** complete simulation ticks from first observed downed (1.2 seconds at 10ms/tick), provided its hitStop is zero and its lane has another unseated enemy; otherwise leave it alone. Record first-down tick once per occupant, reset on replacement. Count completed Match steps, not wall time or KO animation age; evaluate at the end of `Match.step()` (after `run()`/`hitTest()`, the subsequent `enter`/fader work, and all normal script/contact/KO processing), not mid-hit pass. Require `!this.winner && !this.picking && this.fighters[0].hp > 0 && !this.fighters[0].downed`. The HP/downed checks are necessary because `run()` evaluates round-over before its final `hitTest()`; a fresh lethal contact can KO 1P while both result flags are still null. Pin a KO on the exact tick a lane seat becomes eligible; no refill on that tick or during the result transition. If a KO stop is still active at 120, wait until the first eligible boundary. This authored window exceeds the native 40-tick KO hold and permits a bounded KO presentation without waiting for indefinitely held KO animations. Record it in evidence.md; pin age 119, 120 and extended stop cases.

At most one refill per lane at each boundary, stable lane/seat order. If the lane still has a native waiting successor, do not retire the watched predecessor (or refill that lane) until `arrive()` has run and it has entered. Once both occupants entered, retire an eligible KO, copy the next enemy into that same seat as a normal waiting slot and update the lane's latest-assigned seat. Its watch is:
- If the most recently assigned predecessor is in the other seat, watch that seat with `below = desperationOf(predecessor.who)` and native re-read semantics.
- If the predecessor itself is the retired occupant (newer enemy KO'd before older enemy), its KO already satisfied the gate. Set watch to an explicitly absent story seat (-1) and below to the retired predecessor's positive desperation mark; native `bySeat`/ `arrive` resolves missing life to zero, so it enters on the next native arrival pass. No threshold latch.
- On two KOs together, refill one seat only; let its waiting replacement enter while the other downed predecessor still exists (or via absent-seat watch), then consider the other seat. Never overwrite a slot still being watched. A freshly waiting replacement at full HP cannot trigger another refill. The other lane is independent.

These guards are necessary corrections to the review's proposed unconditional other-seat watch and simultaneous refill: A2 could KO before A1, and replacing a watched A2 with full-life A4 before A3 arrives would block the queue. Test both orders and simultaneous KOs; do not require older enemies to die first. An enemy still alive above its current threshold can delay the next entrant, as in native B.R. Use the existing arrival phase, strict below comparison and scaled mark; 1P ally keeps native waiting behavior.

## 3. Scene: non-blocking lookahead, seated-only residency gate

`whenReady` loads only initially seated fighters, not the queue. Reuse `loadPlayer`, `residentPack`, `unloadPlayers`, loader COMPLETE/error handling and `wanted` match identity. Match exposes only the next unseated Who in each lane as lookahead. Keep set = seated (including waiting/KO'd natives) ∪ current summons ∪ at most one unseated queue head per lane.

**Prefetch asynchronously, never gate on an unseated head.** After begin and each refill/unload sweep, call existing `loadPlayer` / loader start for up to two missing lookahead heads; adopt completed resident packs in `players`. Reuse loader key/residency dedupe and one completion check per actual load batch, not a new listener or repeated start every tick. Do not set `this.loading = true` for background prefetch: the arena keeps ticking and inputs/menu/summons remain available. A slow future pack must not stall tick 0 or the next tick after every refill.

**Gate only seated fighters before each actual fixed step.** Adopt already resident packs using `residentPack(who)`; if any current `match.fighters` pack is not resident, use the same loader (including a prefetch already in flight), skip that step and reset the fixed clock so load-time ticks never catch up. Resume automatically once resident, not by resetting/restarting the Match or music. A refill happens only at the very end of step T, creates a fresh native *waiting* slot with `present=false, shown=false`, no opening, effects, trail or sounds, and clears any HUD rival index naming that retired seat. During T's scene sound/idle/draw phase, the new fighter has no pack-dependent output: idle VM construction uses bundled JSON, waiting actors do not step idle or render poses/life bars, there is no trail/effect, and the old rival index is cleared. T+1 checks the new **seated** fighter's pack before native `arrive()` can use it. Test this exact boundary, including several fixed ticks in one animation frame. No simulation gate on the next *unseated* head; whether a pack finished affects wall-clock waiting only, not which simulation tick performs the arrival.

Use the existing scene error path for a failed active required pack, including a shared summon/prefetch load whose error was otherwise scoped to the summon. On COMPLETE verify actual residency, not just an event; a superseded callback may record actual resident packs, but only the current `wanted === match` / active match may evaluate its missing packs or change its loading/error state. Drop irrelevant late-resident packs at the current match's next safe keep-set sweep; do not allow a stale background-only failure to fail an unrelated newer match. Keep existing transition/summon request ownership and errors, no recoverable retry UI, no generation-token subsystem. Loader callbacks never install a fighter or advance the Match; only fixed steps consume queues.

Extract the small scene per-seat installation from spawnSummon (idle VM initialization, idling flag, palette, sprite pool). Track current per-seat Fighter identity in a distinct `seated: Fighter[]`, reset in `begin()` / `resetIdle()` and update through shared install for summons/refills. Do not repurpose existing `drawn` WeakMap (fader color state). Detect `match.fighters[i] !== seated[i]` immediately after step, before sounds/idle/draw. Stop and remove each retired-seat voice instance keyed `${i}:` in `this.voices` (not the shared audio key, which other seats may still use); clear stale visuals, install fresh idle VM/palette, preserve all other seat voices. Unload the retired-only pack after its simulation/render references are detached (existing unloadTextures resets image textures/removes sounds); before requesting the newly exposed lookahead, sweep keep set. If another occupant/summon/head shares its Who, retain the pack. Do not restart the match via whenReady. Bound ≤6 seated natives + ≤2 unseated heads + actual summons, boot/stage assets separate (transient stale loads from old matches are swept). Phaser-stub tests prove non-blocking delayed lookahead, blocking only on seated misses, correct resume, and bounded wanted/resident sets. One committed refill-with-load E2E confirms the real renderer/load path. No generalized streaming framework.
