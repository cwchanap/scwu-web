## Acceptance criteria (all automated / MCP; no human acceptance)

### Functional and deterministic coverage

- [ ] All 34 eligible regulars get CHAOS; four bosses and non-mode-select fighters do not. Each pair remains ordered and adjacent, pool exclusions and counts exactly 34/36, all four bosses present once, no own-pair/mate duplicate, seeded reproducibility and multiple seeds produce different permutations; source fixtures unmodified. Continue retains ordering, new route consumes a new seed. Demo 23 only, BR Boss Base (15), time=0, one round and normal end.
- [ ] First pair member and first boss immediate; ally waits for 1P's strict native/scaled low-life threshold. Each queue's next entrant waits for that lane's latest entered predecessor below its mark; two-body overlap allowed but maximum six native actors/seats; if both occupied, entry waits for KO retirement. No other lane progress trigger, no pre-entry cascade, no starvation if both occupants KO; complete independently when one lane finishes earlier. Parameterized full 34/36 simulations through multiple reuse cycles and simultaneous KOs; per-tick native/hostility mask invariants. Pair mates friendly and all other pairs mutually hostile; bosses all mutually hostile including one another; player/ally friendly. No-revive and native stats (not tough) preserved. KOs by any actor count once, including repeat KO protections and zero-HP fallback. Correct delayed ally for special pair, no-partner and summons; summons don't count or occupy lane seats.
- [ ] Logical remaining decreases 34/36 to 0, never negative, no win with pending enemies even if all current occupants KO, 1P KO loses (including simultaneous final enemy KO), zero with 1P alive wins; ordinary result and Continue Yes/No return as specified. On retry HP/queues/count/cheats freshly installed; order stays same. Outside CHAOS HUD and results unchanged.
- [ ] Recycling tests cover KO reward/stop before swap, no stale projectile/effect/throw/caught/target/HUD/CPU input/sound/palette/idle ownership, preserving unrelated fighters/effects/tick and cheat settings. Full native set max 6, bounded summons max 10 total in CHAOS; no shift past bitmask capacity. At most 6 seated native packs plus 2 unseated lookahead native packs, plus actual summoned packs; retired-only packs released safely, not all roster at once. Fail/cancel load safely and retry/re-enter without stale callback. No permanent freezes, missing assets, render exceptions, or excessive memory growth.
- [ ] Art pipeline tests verify deterministic composited violet sign, unchanged native art, correct dimensions/alpha, unique renderer key/metadata, mode-select-only residency, authored fingerprint changes on lettering mutation in Python, shell/CI and TS, updated asset version/manifest. Four board bounds and cursor on canvas, keyboard/tap/wrap/recall, boss recall fallback, original routes and LONG retained.
- [ ] `bun run validate` (assets + format/lint/check/test) and `bun run e2e` pass; use existing configured/unconfigured suites as applicable. Full progression is covered by deterministic simulation, not a long wall-clock CI playthrough. Capture actual command results (not simulated). If handoff is missing use existing R2 fixture/art path per AGENTS/CI and verify exporter fingerprint; asset-dependent tests must actually run, not pass by skip. Do not claim validation if blocked.
